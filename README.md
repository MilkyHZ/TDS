# Game Development Project

## Project Description
This repository contains the source code and implementation for our course project. The project focuses on core gameplay mechanics, custom logic architecture, and interactive scene configurations. 

* **Current Status:** Tower Defense System (TDS) Framework implementation.

---

## Setup & Installation
1. **Clone the Repository:**
   ```bash
   git clone <YOUR_REPOSITORY_LINK>
   ```
2. **Open Project:** Launch the root folder in your Game Engine/IDE.
3. **Run:** Locate the main scene or entry file and press **Play**.
